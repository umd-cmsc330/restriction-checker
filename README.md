# Synopsis
[![OCaml-CI Build Status](https://img.shields.io/endpoint?url=https://ocaml.ci.dev/badge/umd-cmsc330/restriction-checker/main&logo=ocaml)](https://ocaml.ci.dev/github/umd-cmsc330/restriction-checker)

`synopsis` is a package used by CMSC330: Organization of Programming Languages to enforce project restrictions via OCaml's parsetree. In its current state it's meant to be used in conjunction with unit testing to ensure restrictions are met, though this will hopefully be integrated into the package in the future.

To install the most recent version of `synopsis`, use this command:
```
$ opam install synopsis
```
